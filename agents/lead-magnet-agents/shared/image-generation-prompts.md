# Image Generation Prompt Templates

Reference guide for constructing AI image prompts using Glif's Nano Banana Pro. Use this in the Image Generation Agent when creating quiz assets, product imagery, and landing page heroes.

---

## Prompt Engineering Framework

### Base Template Structure

```
[SUBJECT] based on [DESCRIPTION]
[BRAND STYLE ADJECTIVES] aesthetic
[PHOTOGRAPHY STYLE] photography
[LIGHTING DIRECTION] from [POSITION]
[QUALITY BOOSTERS]
```

### Quality Boosters (Add to all prompts)
- "Ultra-detailed"
- "Commercial quality"
- "Professional photography"
- "Sharp focus"
- "8K resolution"
- "Magazine-quality"

## 7. Common Pitfalls & Fixes

### ❌ Too Generic
**Bad:** "A business person in an office"
**Good:** "Confident female business owner reviewing growth analytics on modern laptop in organized home office with natural light"

### ❌ Too Complex
**Bad:** "Luxury candle with intricate baroque patterns on ornate Victorian table with velvet curtains and crystal chandelier with sunset light through stained glass"
**Good:** "Luxury scented candle in matte black vessel on white marble surface with soft window light"

### ❌ Missing Quality Cues
**Bad:** "Modern living room"
**Good:** "Modern living room interior, magazine quality, architectural photography, sharp focus, 8K, Dwell magazine style"

### ❌ Contradictory Elements
**Bad:** "Minimalist cluttered office with vintage modern furniture"
**Good:** "Minimalist modern office with sleek furniture and clean lines"

### ❌ Vague Lighting
**Bad:** "Good lighting"
**Good:** "Soft natural window light from upper left with subtle fill light from right"

## 8. Usage in Image Generation Agent

When constructing prompts:

1. **Extract brand context** from research.md (archetype, colors, industry)
2. **Choose appropriate template** based on image purpose
3. **Customize subject** based on specific product/service
4. **Map brand archetype** to style adjectives using table above
5. **Add industry-appropriate** photography style
6. **Include quality boosters** for consistency
7. **Validate prompt** against common pitfalls

**Output format:**
```json
{
  "prompt": "[constructed prompt text]",
  "aspect_ratio": "16:9|1:1|4:5",
  "purpose": "landing_hero|product_image|quiz_option|concept",
  "brand_alignment": "Matches [archetype] aesthetic from brand analysis"
}
```

---

## 9. Aspect Ratio Guidelines

| Image Purpose | Recommended Ratio | Reasoning |
|---------------|-------------------|-----------|
| **Landing Page Hero** | 16:9 or 21:9 | Wide cinematic, room for headline overlay |
| **Product Images** | 1:1 or 4:5 | Square for grid layout, portrait for e-commerce |
| **Quiz Options (Images)** | 4:5 | Portrait for visual impact in grid |
| **Concept Images** | 16:9 | Landscape for environmental scenes |
| **Social Sharing** | 1:1 | Universal compatibility |
