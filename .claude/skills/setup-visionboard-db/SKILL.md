# Setup Vision Board Database

Automate Supabase database setup for vision board builders generated by `/lead-magnet-vision-board`.

## Trigger

```
/setup-visionboard-db [business-name]
```

If no business name provided, list available vision board projects and ask which one to set up.

---

## Prerequisites

Before running this skill, the user must have:
1. A Supabase project created at [supabase.com](https://supabase.com)
2. A Glif account with API token from [glif.app](https://glif.app)
3. The following credentials ready:
   - Project URL (from Settings > API)
   - Service Role Key (from Settings > API)
   - Database URL (from Settings > Database > Connection string)
   - Database password (used when creating the project)
   - Glif API token (from Glif account settings)

---

## Workflow

### Step 1: Locate the Vision Board Project

1. If business name provided, construct path:
   ```
   output/[business-name]/
   ```

2. If no business name, list available projects:
   ```bash
   ls output/
   ```
   Then ask user which one to set up.

3. Find the deploy folder with package.json (handles nested structure):
   ```bash
   find [output-folder] -name "package.json" -path "*/deploy/*" | head -1
   ```
   The folder containing this package.json is where we run commands.

### Step 2: Verify Vision Board Project Exists

Check that required files exist:
- `package.json` with `setup-db` script
- `.env.example` template
- `scripts/setup-schema.js`
- `supabase/schema.sql`
- `api/generate-graphic.js` (vision board specific)
- `api/visionboard-submit.js` (vision board specific)

If any are missing, report error and exit.

### Step 3: Collect Credentials

Ask the user for their Supabase and Glif credentials. Present this message:

```
I need your Supabase and Glif credentials to set up the database.

**From Supabase Dashboard:**

1. **SUPABASE_URL** (Settings > API > Project URL)
   Example: https://abcdefgh.supabase.co

2. **SUPABASE_SERVICE_ROLE_KEY** (Settings > API > service_role key - the secret one)
   Example: eyJhbGciOiJIUzI1NiIs...

3. **SUPABASE_DB_URL** (Settings > Database > Connection string > URI)
   - Replace `[YOUR-PASSWORD]` with your database password
   Example: postgresql://postgres:mypassword@db.abcdefgh.supabase.co:5432/postgres

**From Glif:**

4. **GLIF_API_TOKEN** (from your Glif account settings)
   Example: glif_abc123...
   This is used for runtime graphic generation when users complete the builder.

**Configuration:**

5. **TABLE_PREFIX** (default: [initials]_)
   This prefixes all tables: [prefix]leads, [prefix]selections, etc.

6. **ADMIN_PASSWORD** (for /admin analytics dashboard)
   Choose a secure password.
   **IMPORTANT**: Avoid special characters like `!` `$` `\` `` ` `` - they cause shell escaping issues with Vercel CLI.
   Use alphanumeric characters and simple symbols (`-` `_` `.`) only.

**Optional:**

7. **GUMLOOP_WEBHOOK_URL** (for automation triggers)
   Leave blank if not using Gumloop.

8. **RESEND_API_KEY** (for email sending)
   Leave blank to skip email functionality.

Please provide these values (you can paste them all at once or one by one):
```

### Step 4: Create .env File

After collecting credentials, create the `.env` file in the deploy folder:

Content template:
```
# [Business Name] Vision Board Builder - Environment Variables
# Generated by /setup-visionboard-db on [date]

# Supabase Configuration (Required)
SUPABASE_URL=[value]
SUPABASE_SERVICE_ROLE_KEY=[value]
SUPABASE_DB_URL=[value]

# Table Prefix (Required)
TABLE_PREFIX=[value]

# Glif Configuration (Required for graphic generation)
GLIF_API_TOKEN=[value]
GLIF_MODEL_ID=cmi7ne4p40000kz04yup2nxgh

# Admin Dashboard
ADMIN_PASSWORD=[value]

# Automation Webhook (Optional)
GUMLOOP_WEBHOOK_URL=[value]

# Email Configuration (Optional)
RESEND_API_KEY=[value]
```

### Step 5: Install Dependencies

```bash
cd [deploy-folder] && npm install
```

Report progress and any errors.

### Step 6: Run Database Setup

```bash
npm run setup-db
```

This should output:
```
Connecting to database...
Creating tables with prefix: [prefix]
  - Created [prefix]leads
  - Created [prefix]selections
  - Created [prefix]recommended_services
  - Created [prefix]email_log
  - Created [prefix]email_templates
  - Created [prefix]analytics_events
  - Created [prefix]graphic_cache
Seeding email templates...
  - Seeded 10 email templates
Database setup complete!
```

If there are errors, report them clearly.

### Step 7: Test Glif API Connection

After database setup, test the Glif API connection:

```bash
# Quick test of Glif API connectivity
node -e "
const token = process.env.GLIF_API_TOKEN || '[token-from-env]';
fetch('https://simple-api.glif.app', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    id: 'cmi7ne4p40000kz04yup2nxgh',
    inputs: ['test image, simple gradient background, minimal, 8K']
  })
}).then(r => r.json()).then(d => {
  if (d.output) console.log('Glif API connected. Test image:', d.output);
  else console.log('Glif API error:', JSON.stringify(d));
}).catch(e => console.error('Connection failed:', e.message));
"
```

If test fails, warn user but do not block setup. Glif is needed for runtime graphic generation but the builder will work without it (falls back to pre-generated profile images).

### Step 8: Verify Setup

1. Confirm tables were created (check script output)
2. Confirm Glif API connection (if tested)
3. Report success with next steps

## Schema Differences from Quiz Funnel

The vision board uses a different data model than the quiz funnel:

| Quiz Table | Vision Board Table | Key Differences |
|---|---|---|
| `{PREFIX}leads` | `{PREFIX}leads` | `quiz_score`/`temperature` replaced by `profile_id`/`qualification_signal`/`tags[]` |
| `{PREFIX}quiz_responses` | `{PREFIX}selections` | JSONB `selected_options` + `tags[]` instead of `question_id`/`answer_id`/`score` |
| `{PREFIX}recommended_products` | `{PREFIX}recommended_services` | No `price` field, adds `match_reason` |
| `{PREFIX}email_templates` | Same structure | 10 templates across 4 sequences (not 14 across 5) |
| `{PREFIX}email_log` | Same structure | Unchanged |
| `{PREFIX}analytics_events` | Same structure | New event types for builder flow |
| (none) | `{PREFIX}graphic_cache` | Caches Glif-generated images by selection hash |

### New Analytics Event Types

The vision board tracks different events than the quiz:
- `builder_start` - User starts the builder
- `selection_made` - User makes a selection in a step
- `email_captured` - User provides email
- `board_generated` - Vision board graphic is generated
- `board_downloaded` - User downloads their board
- `board_shared` - User shares their board (social)
- `recommendation_clicked` - User clicks a service recommendation
- `consultation_cta_clicked` - User clicks the consultation CTA

## Error Handling

### Vision Board Project Not Found
```
Vision board project "[name]" not found.

Available projects:
- [list projects]

Usage: /setup-visionboard-db [business-name]
```

### Missing Files
```
Missing required files in deploy folder:
- [list missing files]

This vision board may have been generated with an older version.
Please regenerate using /lead-magnet-vision-board.
```

### Database Connection Error
```
Database connection failed.

Check your SUPABASE_DB_URL:
- Is the password correct?
- Did you replace [YOUR-PASSWORD] with your actual password?
- Is the Supabase project active (not paused)?

Error: [actual error message]
```

### Tables Already Exist
```
Some tables already exist in the database.

To reset and recreate, run this SQL in Supabase SQL Editor:
DROP TABLE IF EXISTS [prefix]graphic_cache;
DROP TABLE IF EXISTS [prefix]analytics_events;
DROP TABLE IF EXISTS [prefix]email_log;
DROP TABLE IF EXISTS [prefix]email_templates;
DROP TABLE IF EXISTS [prefix]recommended_services;
DROP TABLE IF EXISTS [prefix]selections;
DROP TABLE IF EXISTS [prefix]leads;

Then run /setup-visionboard-db again.
```

### Glif API Connection Failed
```
Glif API connection test failed.

Check your GLIF_API_TOKEN:
- Is the token correct? (should start with "glif_")
- Is your Glif account active?

The builder will still work without Glif (falls back to pre-generated profile images),
but personalized vision board graphics will not generate.

You can add/fix the GLIF_API_TOKEN in your .env file later and redeploy.
```

## Notes

- This skill does NOT create the Supabase project - user must do that first
- This skill does NOT deploy to Vercel - it just sets up the database
- Credentials are stored in `.env` which is gitignored
- Glif API is tested but not required - the builder has fallback images
- The GLIF_MODEL_ID default (`cmi7ne4p40000kz04yup2nxgh`) is Nano Banana Pro Text 2 Image
- Email templates are seeded from the CSV generated by the VB Copy Agent (10 emails, 4 sequences)
